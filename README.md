# Atelier Zéphyr

Cas fictif de start-up de drones, à usage pédagogique. Toutes les données sont des hypothèses.

Deux parcours : **DU PaRéO** (chiffres ronds) et **DSCG / Master** (deux décimales, projet de contrôle de gestion).

## Fichiers

- `index.html` : page d'accueil et structure
- `app.js` : interface et navigation
- `engine.js` : moteur de calcul de la simulation
- `content.js` : contenu du cas
- `lecons.js` : leçons et exercices
- `fichiers.js` : fichiers à télécharger

Ouvrir `index.html` dans un navigateur, ou le publier sur un hébergement statique.

## Classeur Excel

- `classeurs/Atelier_Zephyr_DU_DSCG.xlsx` : leçons, exercices, simulation individuelle (DU) et projet d'écarts (DSCG). Les onglets « Corrigé » contiennent les réponses : à retirer avant de diffuser le classeur aux étudiants.
